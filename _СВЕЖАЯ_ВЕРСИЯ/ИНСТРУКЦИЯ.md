# ИНСТРУКЦИЯ — установка v2.0.0 «с нуля»

Эта папка `_СВЕЖАЯ_ВЕРСИЯ` содержит **все 22 файла** проекта в новой редакции с префиксом `_Advice_*` для всех вкладок рекомендаций. Идёте сверху вниз. Каждый шаг ссылается на конкретный файл рядом — открываете его, копируете целиком, вставляете в редактор Apps Script. Никаких патчей, никаких «оставьте старое, замените это».

> **Где вы сейчас:** работаете в копии `1vqZnJ_DxStg6T8mmp2KhUj3ww1MXBqpki2OX5upa35Q` (Шампунь Савач выпадение 250 мл). Все шаги ниже надо повторить для каждой копии, в которой хотите получать рекомендации.

---

## 0. Что такое «выбор РП» (отвечаю сразу)

В файле есть вкладка «выбор РП» — рекламная полка. Я её **не перезаписываю никогда**. Маркетолог сам туда руками вносит, какие категории рекламной полки хочет рассмотреть, какой бюджет, какие ограничения. Скрипт её **читает** перед запуском Claude — её содержимое идёт в промпт как «пожелания маркетолога», и Claude учитывает их при формировании `_Advice_Shelf_Strategy`.

Если вкладки нет вообще — скрипт пройдёт без неё, использовав только семядро и данные MarketGuru-полок. Если вкладка пустая — то же самое. Если хотите донести до Claude конкретику вроде «бюджет на полки 50 000 ₽/мес, не идём в `здоровье и красота → бады`» — просто пишете это в любых ячейках «выбор РП», скрипт прочитает первые 80 строк.

## 3. Сохранить и авторизоваться

1. Ctrl+S во всех вкладках редактора.
2. Сверху редактора в селекторе функций выберите **`setupServiceSheets`** → нажмите ▶ «Выполнить».
3. Google спросит разрешения — пройдите OAuth до конца (Advanced → Go to project → Allow). Это нужно один раз для этой копии — она независимый Apps Script проект.
4. После завершения вернитесь в таблицу. Должны появиться вкладки: `_Config`, `_StopWords`, `_Logs`, `_SemanticCore`, `_MissingKeywords`, `_Dashboard`, `_KeywordsRaw`, `_Scoring`, `_Advice_SEO_Draft`, `_Advice_Ad_Strategy`, `_Advice_Logistics`, `_Advice_Shelf_Strategy`, `_Advice_Competitor_Analysis`, `_Advice_Implementation_Tracker`.

## 4. Задать параметры

1. Откройте вкладку `_Config` и убедитесь:
   - `OUR_SKU` = `13771816` (артикул Савач выпадение 250 мл).
   - `OUR_PRODUCT_NAME` = `Шампунь Савач против выпадения 250 мл` (или ваше точное название).
   - `MIN_FREQUENCY` = `30` (для семядра нишевого товара 50 многовато).
   - `CLAUDE_MODEL` оставьте `claude-sonnet-4-5-20250929`.
   - `CLAUDE_MAX_TOKENS` оставьте `8000`.
2. Если у вас есть папка для архива конвертированных файлов — пропишите её ID в `ARCHIVE_FOLDER_ID`.
3. Закройте вкладку.

## 5. Положить Claude API ключ

1. Перезагрузите таблицу (Ctrl+R) — в меню сверху появится **🤖 Конкурентный анализ**.
2. Меню → **🛠 Сервис → 🔑 Задать Claude API ключ**.
3. Вставьте свой ключ `sk-ant-…` → ОК.

> **Безопасность.** Ключ сохраняется в **User Properties** именно вашего аккаунта. Другие пользователи таблицы (даже редакторы) его прочитать через `PropertiesService.getUserProperties()` не смогут — у них своя область. Однако человек с правом редактирования скрипта может изменить код и заставить его слить ваш ключ в любую сторону. На периметре 130 SKU это станет проблемой — нужен Web App с «Execute as: Me» (см. пункт 9 ниже).

## 6. Загрузить данные

### 6.1. WB «Сравнение карточек»

1. Меню → **📥 Загрузить отчёт WB (XLSX)…**
2. В сайдбаре оставьте режим «🔄 Обновить эту таблицу» → выберите XLSX → «Загрузить и обработать».
3. Дождитесь сообщения «Готово». В `_Logs` последняя строка должна быть `OK`, и среди шагов виден `артикулов с запросами=5`.

### 6.2. MarketGuru (по желанию, но **очень** улучшает рекомендации)

1. Скачайте из MarketGuru:
   - **Анализ по артикулу → Кластеры** для каждого из 5 артикулов (5 файлов).
   - **Карточка товара → Мониторинг полок** для каждого из 5 артикулов (5 файлов).
2. Меню → **📊 Загрузить файлы MarketGuru…**
3. В сайдбаре: в «🔵 Кластеры» выберите все 5 файлов кластеров; в «🟢 Мониторинг полок» — все 5 файлов полок.
4. Нажмите «Загрузить и записать». Если очередь не успеет за 6 минут — скрипт сам поставит триггер и продолжит. Через минуту увидите движение в `_Logs`.

### 6.3. Пожелания по рекламной полке (по желанию)

1. Откройте вкладку «выбор РП» (если её нет — создайте).
2. В произвольной форме впишите ваши пожелания: интересующие категории полок, бюджет, ограничения. Например:
   - `Бюджет: 80 000 ₽ / мес`
   - `Не идём в: уход за лицом, средства для бритья`
   - `Хотим тестить: уход за волосами, проф. косметика`
3. Скрипт прочитает первые 80 строк этой вкладки и положит в промпт Claude.

## 7. Кнопка «🪄 Сделать семантику + SEO»

1. Меню → **🪄 Сделать семантику + SEO (Claude)**.
2. Скрипт:
   - соберёт top-80 семядра, top-60 missing, top-60 scoring, показатели, склады, MG-кластеры, MG-полки и «выбор РП»;
   - отправит всё одним запросом в Claude;
   - распарсит ответ и заполнит **6 вкладок**:
     - `_Advice_SEO_Draft` — title, описание, характеристики, main/long-tail keywords;
     - `_Advice_Ad_Strategy` — авто- и поисковая кампания, ставки, минус-слова;
     - `_Advice_Logistics` — приоритетные и деприоритезированные склады;
     - `_Advice_Shelf_Strategy` — какие рекламные полки купить / пропустить;
     - `_Advice_Competitor_Analysis` — построчно по каждому конкуренту: сильные/слабые/что делать нам;
     - `_Advice_Implementation_Tracker` — чек-лист внедрения с чекбоксами (его при повторных запусках **не очищаем**, дописываем секцию вниз).
3. Время ~30-90 сек в зависимости от размера данных.

## 8. Что куда смотреть

Откройте `_Dashboard` — внизу появилась секция **«🪄 Рекомендации Claude»** со ссылками на все 6 листов. Это ваш hub.

Маркетологу для повседневной работы достаточно идти по этой пятёрке:

1. `_Advice_SEO_Draft` — взять title + описание + характеристики, вставить в карточку WB.
2. `_Advice_Ad_Strategy` — настроить авто- и поисковую кампанию.
3. `_Advice_Logistics` — заказать поставки на нужные склады.
4. `_Advice_Shelf_Strategy` — выкупить рекламные полки.
5. `_Advice_Competitor_Analysis` — точечные удары по слабым местам конкурентов.
6. `_Advice_Implementation_Tracker` — поставить галочку рядом с выполненным шагом.

## 9. Честно о пределах текущей архитектуры

Я обещал не подслащивать — вот красные флажки на пути к 130 SKU:

1. **Каждая копия — отдельный Apps Script проект.** Чтобы обновить код в 130 копиях, придётся повторять пункты 2–5 в каждой. Это часы рутины. **Стратегическое решение**: рефактор на **Web App с deploy как «Execute as: Me»** + одна master-таблица с реестром SKU. Тогда обновление кода в одном месте мгновенно «прилетает» на все 130 SKU. Это task #17, и пока он не сделан — каждый новый SKU требует ручного раската.
2. **API ключ Claude.** В текущей схеме лежит в User Properties вас лично. Если откроете доступ редактора маркетологу — он не увидит ключ в свойствах, но может прочитать его через `console.log` если допишет код. **Решение**: тот же Web App + «Execute as: Me» — маркетолог в скрипт не лезет, всё идёт через ваш аккаунт.
3. **Лимит 6 минут на исполнение.** Для MG-очереди я этот лимит обошёл через trigger chaining (см. `17_MgQueue.gs`). Для остального — пока в зелёной зоне, но при ассортименте товаров категории «Маркетплейс XL» (50+ конкурентов вместо 4) надо будет дробить и пайплайн WB.
4. **Цена Claude API.** Один запуск `🪄 Сделать семантику + SEO` это ~30K input + 4K output = $0,12. Для 130 SKU = $15 за раунд, $60–180/мес если перезапускаете еженедельно. В рамках разумного, но закладывайте в бюджет.

## 10. Если что-то сломалось

1. Откройте `_Logs` — последняя строка покажет `ERROR` и в столбце «Ошибки» — точное место.
2. Типовые ошибки и решения:
   - `Указанных разрешений недостаточно для UrlFetchApp.fetch` → шаг 2 пропустили: не заменили `appsscript.json`. Проверьте, что в нём есть строка `"https://www.googleapis.com/auth/script.external_request"`.
   - `Claude API ошибка 401` → ключ неверный/протух. Меню → Сервис → 🔑 Задать Claude API ключ.
   - `Claude API ошибка 429` → rate limit. Подождите минуту, повторите.
   - `Файл не соответствует ожидаемой структуре WB` → загрузили не «Сравнение карточек», а другой отчёт.
   - `Нет данных в _KeywordsRaw` → значит не было ни одной успешной загрузки WB. Сначала шаг 6.1.

## Приложение A. Эти 22 файла — единое целое

Не подменяйте отдельные файлы из старых версий. Версия 00_Config v2 знает про `_Advice_*` и `CLAUDE_API_KEY`, а старый 99_Setup эти вкладки не создаст. Если будете дробить апдейт — сломаются ссылки в дашборде и не заработает SEO-пайплайн.
