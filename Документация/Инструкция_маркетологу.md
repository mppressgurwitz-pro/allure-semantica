# Инструкция маркетологу — конкурентный анализ WB за 3 клика

## Сценарий A — обновить уже существующую таблицу того же SKU

1. Скачиваете отчёт «Сравнение карточек» с Wildberries (XLSX).
2. Открываете нашу Google-таблицу «Сравнение конкурентов» по ссылке из закрепа.
3. Меню сверху → **🤖 Конкурентный анализ → 📥 Загрузить отчёт WB (XLSX)…**
4. В сайдбаре оставляете режим по умолчанию **«🔄 Обновить эту таблицу»** → выбираете файл → **«Загрузить и обработать»**.
5. Ждёте, пока зелёные галочки прогресса дойдут до 100%. Готово.

## Сценарий B — новый SKU (создать копию шаблона автоматически)

1. Скачиваете отчёт «Сравнение карточек» с WB по новому товару.
2. Открываете **мастер-шаблон** (любую таблицу, где работает скрипт; для удобства можно открыть исходный шаблон по Савач).
3. Меню → **🤖 Конкурентный анализ → 📥 Загрузить отчёт WB (XLSX)…**
4. В сайдбаре переключаете режим на **«🆕 Создать новую таблицу для другого SKU»**.
5. Заполняете два поля:
   - **Название товара** — попадёт в имя файла-копии (пример: `Шампунь Активспорт 1 л`).
   - **Артикул WB нашего товара** — наш SKU нового продукта (пример: `412345678`). Он автоматически запишется в `_Config` копии.
6. Выбираете XLSX → **«Загрузить и обработать»**.
7. По завершении в сайдбаре появится ссылка на свежесозданную таблицу. Открываете её — там уже всё заполнено: жёлтые вкладки, дашборд, missing keywords.

Альтернатива без файла: меню → **🆕 Создать таблицу для нового SKU (без файла)…** Скрипт спрашивает название и артикул, создаёт пустую копию шаблона. Открываете её и грузите XLSX уже потом, когда будет.

Никаких ручных операций — копировать столбцы, чистить ключи, прописывать артикул в столбец A, делать копии шаблона — больше не нужно. Скрипт делает всё сам.

## Сценарий C — догрузить файлы MarketGuru

В шаблоне есть две вкладки под MG: **🟡 Вставка МГ кластера** и **🟡 Вставка МГ полки**. Скрипт умеет наливать туда данные из выгрузок MarketGuru тем же методом, что и WB.

1. В MarketGuru скачайте отчёты по нашим артикулам:
   - **Анализ по артикулу → Кластеры** — отдельный XLSX на каждый артикул (в ваших выгрузках это были файлы `..._Кластеры_NNN.xlsx`).
   - **Карточка товара → Мониторинг полок** — отдельный XLSX на каждый артикул (имена выгружаются с одинаковым префиксом, MarketGuru добавляет суффиксы 1/2/3/4).
2. Открываете нужную таблицу (мастер или копию под SKU) → меню **🤖 Конкурентный анализ → 📊 Загрузить файлы MarketGuru…**
3. В сайдбаре две секции с мульти-выбором файлов:
   - **🔵 Кластеры** — выбираете все XLSX-файлы кластеров (можно сразу до 9 за раз через Ctrl/Cmd-click или Shift).
   - **🟢 Мониторинг полок** — все файлы полок аналогично.
4. Нажимаете **«Загрузить и записать в шаблон»**. Можно загрузить только Кластеры, только Полки, или оба типа сразу.
5. Артикул для каждой строки берётся **автоматически из ячейки B2 файла** — переименовывать файлы и проставлять артикул вручную не нужно.

После завершения вкладки **🟡 Вставка МГ кластера** и **🟡 Вставка МГ полки** будут содержать слитую таблицу: столбец A — артикул, столбцы B и далее — данные MarketGuru с двухстрочной шапкой, склеенной в один заголовок (например, `Изменение позиции / за 7 дней`).

## Где живут копии

По умолчанию копия создаётся в той же папке Drive, где лежит мастер-шаблон. Если хотите, чтобы копии складывались в отдельную папку (например, `Конкурентный анализ — SKU 2026 Q2`), создайте её, скопируйте её ID из URL и пропишите в листе `_Config` параметр `COPIES_FOLDER_ID`.

## Что появляется автоматически

После обработки в таблице обновятся / появятся вкладки:

- **🟡 Показатели (вставка)** — данные WB по сравнению карточек (цена, рейтинг, воронка по нашему артикулу + 4 конкурентам).
- **🟡 Запросы (вставка)** — все поисковые запросы по каждому артикулу. В столбце A автоматически проставлен номер артикула.
- **🟡 Склады и регионы (вставка)** — остатки и заказы в день по складам.
- **🔴 Сравнение конкурентов** — расчётная вкладка обновится сама (там формулы).
- **_Dashboard** — сводный экран на одной странице: топ-10 наших запросов, топ-20 missing keywords, топ-10 запросов конкурентов, размер семядра.
- **_SemanticCore** — семантическое ядро: уникальные нормализованные запросы по всем артикулам с их частотностью у нас и у конкурентов.
- **_MissingKeywords** — запросы, которые приносят трафик/заказы конкурентам, а у нас отсутствуют. Отсортированы по приоритету (🔴 High → 🟡 Medium → 🟢 Low).
- **_Scoring** — все запросы с автоматическим скорингом (формула учитывает частотность и конверсии).
- **_KeywordsRaw** — нормализованные запросы (для пересчёта без перезагрузки файла).
- **_Logs** — журнал запусков. Если что-то пошло не так — здесь видно почему.

## Как читать дашборд

Вкладка `_Dashboard` показывает:

1. **Параметры запуска** — какой период взят, наш артикул, артикулы конкурентов, размер ядра.
2. **🏆 Top-10 запросов нашего SKU** — это запросы, по которым мы уже хорошо ранжируемся. Их обязательно сохраняем в текстах карточки.
3. **🔍 Top Missing Keywords** — золотая жила. Это запросы, которые работают у конкурентов, но не привлекают трафик к нам. Кандидаты на добавление в текст карточки и SEO-описание.
4. **📊 Top-10 запросов конкурентов** — что прокачали соседи. Используем для понимания, в какую семантическую сторону рынок развивается.

Приоритет в Missing Keywords:
- 🔴 **High** — высокая частотность + хорошая конверсия в заказ → добавлять в первую очередь, в title и main keywords.
- 🟡 **Medium** — есть смысл протестить, добавить в описание / характеристики.
- 🟢 **Low** — на потом или для long-tail SEO.

## Где менять параметры

Откройте лист **`_Config`** (он скрыт, но доступен через меню «Все листы»). Там столбец «Параметр» / «Значение»:

| Параметр | Что делает | Когда менять |
|---|---|---|
| `OUR_SKU` | Артикул WB нашего товара | При смене карточки или работе с другим товаром |
| `MIN_FREQUENCY` | Минимум показов запроса для попадания в семядро | Уменьшаем (например, 10), если ассортимент узкий |
| `MISSING_TOP_N` | Сколько top-missing хранить | По вкусу, обычно 100–300 |
| `SCORE_WEIGHTS` | Веса скоринга в JSON | Меняем баланс между «много показов» и «высокая конверсия» |
| `ARCHIVE_FOLDER_ID` | ID Drive-папки для архива конвертированных файлов | Если хотите автоматически складывать копии |

После изменения — снова запустите обработку (меню → ▶️ Перезапустить обработку последнего файла). Файл загружать заново не нужно.

## Стоп-слова

Лист **`_StopWords`** — построчно слова и фразы, которые **исключаются** из ядра. Например:
- бренды конкурентов: `clear`, `dove`, `head and shoulders`
- мусорные категории: `аргинин`, `салициловая кислота` (вылезают из-за ошибок WB-выгрузки)
- маркетинговые: `скидка`, `купон`, `подарок`

Добавляете строку → перезапускаете обработку → стоп-слова срабатывают.

## Если что-то сломалось

1. Откройте лист `_Logs` — последняя строка покажет, на каком шаге упало и почему.
2. Типовые причины:
   - **«Файл не соответствует ожидаемой структуре WB»** — это не «Сравнение карточек», а другой отчёт. Скачайте правильный.
   - **«Ожидается .xlsx файл»** — загрузили CSV. WB всегда отдаёт XLSX, перекачайте.
   - **«Не найдена вкладка 🟡 Показатели (вставка)»** — кто-то переименовал/удалил жёлтую вкладку шаблона. Восстановите оригинальное имя.
3. Если ничего не помогает — пишите в чат разработчика, прикрепляйте скрин из `_Logs`.

## Важные правила

- Не переименовывайте жёлтые и красные вкладки шаблона.
- Не удаляйте формулы во вкладке `🔴 Сравнение конкурентов` — они подтягивают данные из жёлтых.
- Файл WB загружайте свежий, не редактируйте его в Excel перед загрузкой.
- Один файл WB = одна обработка. Если хотите сравнить два периода — делайте два запуска, скрипт хранит историю в `_KeywordsRaw` (если в _Config включён `KEEP_PREV_DATA = TRUE`).
