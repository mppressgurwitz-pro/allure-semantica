# Автоматизация семантики ВБ — конкурентный анализ

Production-ready Google Apps Script, который превращает выгрузку «Сравнение карточек» с Wildberries в полностью наполненную таблицу конкурентного анализа за один клик.

## Структура папки

```
Автоматизация Семантика/
├── AppsScript/                 # Исходный код Apps Script (12 файлов .gs + 1 HTML)
│   ├── appsscript.json
│   ├── 00_Config.gs
│   ├── 01_Main.gs
│   ├── ...
│   └── Sidebar.html
├── Документация/
│   ├── README.md               # ← вы здесь
│   ├── Инструкция_маркетологу.md
│   └── Инструкция_разработчику.md
└── Референсные данные/         # Папка под тестовые XLSX-выгрузки и т.п.
```

## Что умеет

1. **Загрузка XLSX через сайдбар** — никаких ручных копирований.
2. **Конвертация в Google Sheets** через Drive API v3.
3. **Парсинг 10-ти листов выгрузки WB** включая 5 листов «Поисковые запросы по артикулу N».
4. **Автозаполнение трёх жёлтых вкладок** шаблона по строгим правилам ТЗ — без ломки формул.
5. **Нормализация ключей** — lowercase, ё→е, удаление пунктуации, фильтрация по `MIN_FREQUENCY`.
6. **Стоп-слова** — конфигурируются маркетологом в листе `_StopWords`, без правки кода.
7. **Семантическое ядро** — уникальные запросы с агрегированной частотностью по нашим и конкурентам.
8. **Missing keywords** — что есть у конкурентов и нет у нас. С приоритезацией High/Medium/Low.
9. **Скоринг** — `freq × cart × order` с настраиваемыми весами.
10. **Дашборд** — все KPI на одной странице.
11. **Журнал запусков** — `_Logs`.
12. **Идемпотентный пересчёт** — без перезагрузки файла можно пересобрать дашборд, скоринг, missing.

## Quick start

См. **`Инструкция_разработчику.md`** для деплоя, **`Инструкция_маркетологу.md`** для ежедневной работы.

## Поддержка

- Журнал ошибок: лист `_Logs` в таблице.
- При структурных изменениях в выгрузке WB обновлять `CONFIG.WB_SHEETS` в `00_Config.gs`.
- Версия: см. `CONFIG.VERSION` в `00_Config.gs`.
