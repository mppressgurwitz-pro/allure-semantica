🤖 Конкурентный анализ WB — инструкция

Один прогон → готовый SEO + реклама + логистика + полки. ~5 минут от файла до результата.

1. Открыть таблицу товара

Откройте Google-таблицу «Сравнение конкурентов» по вашему артикулу. Ссылки на копии — в закрепе группы.

2. Загрузить отчёт Wildberries

  1. В WB Партнёры → Аналитика → Сравнение карточек добавьте наш артикул и 4 конкурентов, скачайте XLSX.
  2. В таблице: меню 🤖 Конкурентный анализ → 📥 Загрузить отчёт WB (XLSX).
  3. Режим оставьте «🔄 Обновить эту таблицу» → выберите файл → «Загрузить и обработать».
  4. Дождитесь зелёных галочек прогресса (1–2 минуты).

3. Загрузить файлы MarketGuru (рекомендуется)

  1. Скачайте из MarketGuru по каждому из 5 артикулов: «Кластеры» (Анализ → Кластеры) и «Мониторинг полок» (Карточка → Полки).
  2. Меню → 📊 Загрузить файлы MarketGuru.
  3. В сайдбаре: все Кластеры в одну секцию, все Полки в другую (Ctrl/Shift-клик) → «Загрузить и записать».

4. Сгенерировать рекомендации

Меню → 🪄 Полный пакет рекомендаций: SEO + реклама + склады + полки (Claude)

Подождите 1–3 минуты. Появится сообщение «✅ Готово». Если выскочила ошибка — см. блок внизу.

5. Где смотреть результаты

ВкладкаЧто внутри
_DashboardГлавная страница: KPI и ссылки на все остальные вкладки.
_Advice_SEO_DraftTitle, описание, характеристики и тексты для 6 фото-слайдов инфографики (WB читает OCR со всех фоток).
_Advice_Ad_StrategyСтратегия авто- и поисковой рекламы: ключи, минус-слова, ставки.
_Advice_LogisticsКакие склады приоритезировать для отгрузки, какие пропустить.
_Advice_Shelf_StrategyРекомендуемые рекламные полки + куда не идти. С бюджетами и причинами.
_Advice_Competitor_AnalysisПо каждому из 4 конкурентов: сильные стороны, слабые, что сделать нам.
_Advice_Implementation_TrackerЧек-лист внедрения с галочками. История запусков сохраняется между прогонами.

6. Внедрить и отметить — самое главное

Откройте _Advice_Implementation_Tracker и ставьте галочку напротив каждой выполненной задачи: обновили title, заменили фотки, запустили рекламу, отгрузили на склад и т.д. Лист не очищается между запусками — видна вся история внедрений.

⚠️ Если что-то пошло не так
  • Откройте вкладку _Logs — последняя строка покажет точную причину.
  • «Превышено время ожидания» / «Claude API 503» — повторите кнопку через 2 минуты, обычно проходит.
  • «Claude вернул невалидный JSON» — посмотрите вкладку _Advice_Last_Raw, перезапустите.
  • Любые странности — Михаилу, со скрином из _Logs.
