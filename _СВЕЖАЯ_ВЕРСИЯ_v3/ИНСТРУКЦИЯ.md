## Порядок установки (в новой копии или master-шаблоне)

1. **Открой Apps Script-редактор** копии: меню «Расширения → Apps Script».
2. **Покажи manifest** (если не виден): ⚙ слева сверху → «Параметры проекта» → галка «Показывать файл manifest».
3. **Для каждого файла из этой папки**:
   - Слева в редакторе кликни на файл с тем же именем (или ➕ → Скрипт/HTML, если файла нет).
   - Ctrl+A → Delete → вставь содержимое одноимённого файла из этой папки → Ctrl+S.

## Что делать после установки в master

1. **Один раз**: в редакторе сверху селектор функций → `initMasterFiles` → ▶. Создаст `Etiquettes_Master`, `Rules_Master` в твоей Drive-папке. Если уже существуют — пропустит. Результат: в `_Config` появятся ID мастер-файлов.

2. **Один раз**: `fixAllCopies` → ▶. Обходит все копии в Drive и приводит их `_Config` к эталону (правильные ID мастер-файлов).

3. **Один раз**: `syncTemplateToEtiquettes` → ▶. Синхронит Шаблон_INCI_для_Маши → Etiquettes_Master. Создаёт строки для 1L вариантов (которых нет в инфомодели). В `_Logs` должно быть «СОЗДАНО новых строк = N».

4. **Один раз** на каждого человека: меню → 🛠 Сервис → 🔑 Задать Claude API ключ.

5. **Регулярно**: меню → 🪄 Полный пакет рекомендаций (Claude) — для каждой копии под-SKU после загрузки WB+MG файлов.

## Если что-то не работает

- **«SKU не найден»** — запусти `syncTemplateToEtiquettes`. Если опять — открой `_Logs` копии и пришли мне строку лога.
- **«Превышено максимально допустимое время»** — копия имеет старый код. Перекопируй файлы из этой папки.
- **«Не задан Claude API ключ»** — твоя User Property пустая, задай через меню.
- **`initMasterFiles` зависает на 6 минут** — у тебя старая версия `19_DriveAndMasters.gs`. Перекопируй из этой папки.
