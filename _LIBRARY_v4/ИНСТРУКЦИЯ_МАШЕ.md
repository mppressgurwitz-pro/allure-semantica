# Заполнение колонок I–Q в Шаблоне (для Маши)

**Файл:** [Шаблон_INCI_для_Маши](https://docs.google.com/spreadsheets/d/1z9UxpQ3VCaBNk1zrOdwhui0Apml-uA4UpxuOfCDg8jk/edit) → вкладка `SKU_INCI`
**Зачем:** без этих данных парфюмерия не получит правильное SEO с нотами; наборы будут описаны как одиночные товары.
**Обязательно заполнять:** все парфюмерные SKU (PressGurwitz №1–15 во всех объёмах и категориях) + все наборы. Остальные косметические SKU — по возможности (категория и объём).

---

## Что вписывать в каждую колонку

| Кол. | Заголовок | Что вписывать | Пример |
|---|---|---|---|
| **I** | Категория | Тип продукта одним выражением | `Парфюмерная вода`, `Туалетная вода`, `Дезодорант`, `Лосьон для рук и тела`, `Шампунь`, `Гель для душа`, `Жидкое мыло`, `Свеча`, `Диффузор`, `Крем для рук`, `Соль для ванны`, `Маска для волос`, `Кондиционер`, `Бальзам после бритья`, `Скраб`, `Пилинг`, `Спрей`, `Набор` |
| **J** | Номер аромата | Только цифра. Для PressGurwitz №1–15. Для не-парфюмерии (S&H шампуни) — пусто | `3`, `6`, `15` |
| **K** | Key notes (EN) | Английский оригинал с этикетки, через запятую. Обычно 3 ноты | `Tobacco, Cinnamon, Vanilla` |
| **L** | Ключевые ноты (RU) | Русский перевод нот, через запятую, маленькими буквами | `табак, корица, ваниль` |
| **M** | Объём (мл) | Только число, без «мл» | `10`, `30`, `50`, `300` |
| **N** | Family ID | Любой ID «семьи» — общий у всех вариантов одного аромата в одной категории. Формат `БРЕНД-НОМЕР-КАТЕГОРИЯ` | `PGP-3-EDP`, `PGP-2-LOTION`, `SH-DANDRUFF` |
| **O** | Эталон Y/N | `Y` у ОДНОГО SKU в семье (обычно самый продаваемый объём). У остальных — пусто или `N` | `Y` |
| **P** | Набор Y/N | `Y` если это комплект из нескольких товаров. Видно по названию | `Y` |
| **Q** | Состав набора | Только для наборов: WB-артикулы компонентов через запятую | `445361666, 13771814, 868993506` |

## После заполнения

Когда заполнила хотя бы парфюмерию (PressGurwitz №1–15 во всех формах) и наборы — попроси Михаила:
**Меню `🤖 Конкурентный анализ → 🗂 Мастер-файлы → 🔄 Sync Шаблон → Etiquettes_Master`**

Это перенесёт новые данные в основной мастер-файл. Дальше при генерации SEO любого парфюмерного SKU Claude получает ноты и обязан использовать их в первом абзаце описания. Для наборов — скрипт сам подтянет INCI и ноты всех компонентов по их WB-артикулам.

---

## Что НЕ делать

- **Не путать языки**: английский в K, русский в L.
- **Не ставить `Y` в Эталон у нескольких SKU** одной семьи — только у одного.
- **Не оставлять Состав набора пустым**, если поставила `Набор Y/N = Y`.
- **Не дублировать строки SKU** — один SKU = одна строка.
- **Не вписывать в Состав набора WB-артикул, которого нет в этой же таблице** — без INCI компонента набор не соберётся.
- **Не менять заголовки** в строке 1 — на них завязан синхронизатор.
