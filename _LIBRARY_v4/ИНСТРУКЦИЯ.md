**Что это даёт:**
- 🔁 **Обновление кода** = пересохранить версию библиотеки. Все копии автоматически подхватывают новую логику при следующем открытии.
- 🆕 **Новый SKU** = создать копию + вставить Bootstrap (или копировать из шаблонной копии). 1 минута вместо 30 минут.
- 🐛 **Багфикс** делается в одном месте, не в 130.
- 🧪 **Версионирование** — можешь оставить старые копии на старой версии, новые — на новой.

## Установка (~30 минут разовое)

### Шаг 1 — Создать проект библиотеки

1. Открой <https://script.google.com/home> → **Новый проект**.
2. Назови проект `WBConkAnalysisLib`.
3. ⚙ слева → **Параметры проекта** → ID скрипта — **СКОПИРУЙ И СОХРАНИ**. Это твой `LIBRARY_SCRIPT_ID`. Будет нужен дальше.

### Шаг 2 — Залить код в библиотеку

Содержимое библиотеки — это **все файлы из папки `C:\Users\mb\Documents\Claude\Projects\Автоматизация Семантика\_СВЕЖАЯ_ВЕРСИЯ_v3\`** (та папка с финальным кодом, которую я почти доделал) **+ файл `appsscript.json` из этой папки** (с правильными scopes для библиотеки).

Каждый .gs файл и каждый .html файл вставляешь в библиотечный проект как отдельный файл:
- Слева ➕ → Скрипт (или HTML) → имя файла → вставить содержимое → Ctrl+S
- Для `appsscript.json` — ⚙ Параметры → «Показывать файл manifest» → подмени содержимое

### Шаг 3 — Опубликовать как библиотеку

1. В библиотечном проекте: **Развёртывание** (Deploy) → **Новое развёртывание** → шестерёнка → выбрать тип **«Библиотека»**.
2. Описание: `WBConkAnalysisLib v1` → **Развернуть**.
3. Получишь два значения — нужен **Script ID** (это то, что ты скопировал на Шаге 1).

### Шаг 4 — Bootstrap в каждой копии

Открой одну из существующих копий (например, `Сравнение конкурентов — Савач против перхоти 250 мл`) → **Расширения → Apps Script**.

1. **Удали все .gs файлы** в этой копии (раньше там было 20+). Оставь только `appsscript.json` (он не виден).
2. **Удали HTML-файлы** `Sidebar` и `MgSidebar` если есть.
3. Создай **один** новый файл `Bootstrap` (.gs) → вставь содержимое `Bootstrap.gs` из этой папки.
4. Открой `Bootstrap.gs` → найди константу `LIBRARY_SCRIPT_ID` в начале → вставь туда ID, который ты сохранил в Шаге 1.
5. Слева в редакторе: иконка библиотек **«📚 Libraries»** → ➕ → вставь `LIBRARY_SCRIPT_ID` → Поиск → выбери версию `1` → **Identifier** оставь **`WBLib`** (обязательно именно так, регистрозависимо) → **Добавить**.
6. Ctrl+S.

Повтори для каждой из 4 копий. После этого все они работают через библиотеку.

### Шаг 5 — Проверка

1. Открой одну копию → перезагрузи страницу (Ctrl+R).
2. Сверху должно появиться меню **🤖 Конкурентный анализ**.
3. Нажми любой пункт — проверь что работает.

## Что делать, когда я обновлю код

1. Я выкатываю новую версию `_СВЕЖАЯ_ВЕРСИЯ_vN` с правками.
2. Ты в библиотечном проекте обновляешь измененные файлы.
3. **Развёртывание → Управление развёртываниями** → редактировать существующее → версия «Новая версия» → описание `v2`, `v3`, `vN` → Развернуть.
4. В копиях идти **никуда не надо**. Они автоматически подхватят новую версию при следующем открытии (если в Libraries указано «Развитие» или конкретный номер версии).

Если хочешь, чтобы конкретная копия осталась на старой версии — в её Libraries указать конкретный номер (1, 2, ...).
