# Пошаговая инструкция — переход на WBLib (v3.2)

Время: ~30 минут разово. После этого 20 новых SKU = 10 минут на все.

---

## ЭТАП 1 — Создать проект библиотеки (5 минут)

1. Открыть https://script.google.com/home
2. Нажать **«Новый проект»** (синяя кнопка слева сверху)
3. Сверху, где написано **«Untitled project»** — переименовать в `WBConkAnalysisLib`
4. Слева в редакторе кликнуть иконку **⚙ (Настройки проекта)** в самом низу
5. Скопировать **Script ID** (длинная строка вида `1abc...XYZ`). **Сохрани его в блокнот — он нужен дальше.**

---

## ЭТАП 2 — Залить код в библиотеку (10 минут)

Файлы находятся в `C:\Users\mb\Documents\Claude\Projects\Автоматизация Семантика\_СВЕЖАЯ_ВЕРСИЯ_v3\`.

### 2.1 — Manifest

1. В новом проекте ⚙ **Параметры проекта** → поставить галку **«Показывать файл манифеста appsscript.json в редакторе»**.
2. В редакторе слева открыть `appsscript.json`.
3. Скопировать содержимое из `_СВЕЖАЯ_ВЕРСИЯ_v3/appsscript.json`, вставить, **Ctrl+S**.

### 2.2 — .gs файлы

Для КАЖДОГО из 23 файлов:

1. Слева ➕ рядом с «Файлы» → **Скрипт**
2. Имя — точно как у файла, но **без `.gs`** на конце (Apps Script добавит сам). Пример: `00_Config`, `01_Main`, `02_UI`, …, `24_QuickFix`.
3. Открыть соответствующий файл в `_СВЕЖАЯ_ВЕРСИЯ_v3/` → скопировать содержимое → вставить → **Ctrl+S**.

Порядок (по нумерации):

```
00_Config, 01_Main, 02_UI, 03_Importer, 04_Mapper, 05_Cleaner, 06_Semantics,
07_Scoring, 08_Dashboard, 09_Logger, 10_Validator, 11_KeywordsRaw, 12_Copier,
13_MgImporter, 14_MgMapper, 15_MgUI, 17_MgQueue, 18_SEO, 19_DriveAndMasters,
20_InciImport, 21_ImportFromInfomodel, 22_SyncTemplateToEtiquettes,
23_FixAllCopies, 24_QuickFix
```

Файла `16_*` нет в списке — это нормально, нумерация со скипом.

### 2.3 — HTML файлы

1. Слева ➕ → **HTML** → имя `Sidebar` → скопировать `Sidebar.html` → **Ctrl+S**
2. Слева ➕ → **HTML** → имя `MgSidebar` → скопировать `MgSidebar.html` → **Ctrl+S**

### 2.4 — Проверка компиляции

В выпадающем меню сверху рядом с кнопкой Run выбрать функцию `onOpen` → **Run** один раз. Если Apps Script просит авторизацию — нажать **Review permissions** → выбрать аккаунт Михаила → **Allow**. Если ошибка компиляции — посмотри что красное в логе и пришли скриншот.

## ЭТАП 3 — Опубликовать как библиотеку (3 минуты)

1. В библиотечном проекте сверху справа — **«Развернуть» → «Создать развёртывание»**.
2. Кликнуть **⚙ (шестерёнка)** рядом с «Тип развёртывания» → выбрать **«Библиотека»**.
3. Описание: `WBConkAnalysisLib v1` → **«Развернуть»**.
4. Закрыть диалог. Готово.

---

## ЭТАП 4 — Подключить библиотеку к первой копии (10 минут)

Берём ОДНУ копию, например `Сравнение конкурентов — Савач против перхоти 250 мл`.

### 4.1 — Открыть редактор скрипта

1. Открыть таблицу в Google Sheets.
2. Меню **Расширения → Apps Script**.

### 4.2 — Удалить старые файлы

1. Слева в списке файлов — навести на каждый `.gs` и `.html` → **⋮ → Удалить**.
2. Оставить только `appsscript.json` (его не видно, но он есть).

Все 20+ файлов будут заменены одним Bootstrap.gs.

### 4.3 — Создать Bootstrap.gs

1. Слева ➕ → **Скрипт** → имя `Bootstrap`
2. Открыть `_LIBRARY_v4/Bootstrap.gs` → скопировать целиком → вставить → **Ctrl+S**.

### 4.4 — Подключить библиотеку

1. Слева кликнуть иконку **📚 Libraries** (если нет — кликнуть **+** рядом с «Libraries»).
2. В поле **Script ID** вставить **тот ID из ЭТАПА 1.5** → **«Поиск»**.
3. **Version** — выбрать `1` (или `HEAD` если хочешь, чтобы любые правки кода появлялись сразу без re-deploy. Я бы советовал `1` сначала, для контроля).
4. **Identifier** — должно быть строго **`WBLib`** (регистр важен!).
5. **Добавить** → **Ctrl+S**.

### 4.5 — Проверка

1. Закрыть редактор скрипта.
2. Обновить страницу с таблицей (Ctrl+R).
3. В меню сверху должно появиться **🤖 Конкурентный анализ**.
4. Нажать любой пункт — должно отработать. Если ругается «WBLib не подключена» — Identifier не совпал.

### 4.6 — Перенос правил v3.1

После того как меню работает:

1. **🤖 Конкурентный анализ → 🗂 Мастер-файлы → 📜 Перенести Rules_Master на v3.1**
2. Подтвердить. Старая версия правил сохранится в листе `Правила_backup_<дата>`.

## ЭТАП 5 — Размножить Bootstrap на остальные 3 существующие копии (5 минут)

Для каждой из оставшихся копий:

1. Открыть таблицу → Расширения → Apps Script
2. Удалить все `.gs` и `.html` (как в 4.2)
3. ➕ → Скрипт → имя `Bootstrap` → вставить тот же код из `_LIBRARY_v4/Bootstrap.gs`
4. 📚 Libraries → ➕ → тот же Script ID → версия `1` → Identifier `WBLib`
5. **Ctrl+S** → обновить таблицу → проверить меню

## ЭТАП 6 — Подготовить мастер-шаблон для новых SKU (3 минуты)

Чтобы при создании новой копии она уже была с Bootstrap внутри:

1. Открыть мастер-шаблон (та таблица, ID которой стоит в `MASTER_TEMPLATE_ID` в `_Config` любой из копий).
2. Расширения → Apps Script.
3. Те же шаги, что в Этапе 4: удалить старые файлы → создать `Bootstrap.gs` → подключить `WBLib`.

После этого `🆕 Создать таблицу для нового SKU` будет давать копию, уже готовую к работе.

## ЭТАП 7 — Сегодняшние 20 новых SKU

Для каждого SKU:

1. В любой из работающих копий — **🤖 → 🆕 Создать таблицу для нового SKU**
2. Ввести название и артикул WB
3. Открыть созданную копию (ссылка в диалоге)
4. Меню **🤖 → 📂 Подтянуть из Drive Маши** или **📥 Загрузить отчёт WB вручную** → загрузить выгрузку
5. Когда отработает, запустить **🪄 Полный пакет рекомендаций**

Время на один SKU: 30 сек на копию + 1-2 минуты на загрузку файла + 30-60 сек на Claude. Итого по 20 SKU: ~30-40 минут общего времени, из них активно ты тратишь ~10 минут.

## Если что-то пошло не так

| Симптом | Что проверить |
|---|---|
| «WBLib не подключена» — меню-заглушка | В Libraries: Identifier ровно `WBLib`, Version выбрана, Script ID правильный |
| «Скрипт не имеет полномочий» | В библиотеке запустить любую функцию вручную один раз — Apps Script попросит авторизацию |
| Меню вообще не появилось | Обновить страницу (Ctrl+R). Если нет — в Apps Script меню Triggers → создать триггер `onOpen` от руки |
| Сидебар выдаёт «Функция не найдена» | В Bootstrap.gs нет обёртки для этой функции. Скопировать актуальный Bootstrap.gs заново |
| После обновления библиотеки копии работают по-старому | В Libraries у копии — Version: переключи на новый номер (например с 1 на 2) после нового деплоя библиотеки. Либо изначально ставь HEAD |
